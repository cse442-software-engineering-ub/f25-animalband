# Onboarding Information for New Developers
Welcome to ANIMALBAND, a site modeled after BongoCat, where you can use keyboard inputs to make animals play instruments! Multiple tracks can be recorded with band members of your choice by pressing different keys.

### Directory Structure
Highest level directories:

php: Contains all backend code
phpstuff: (Now obsolete. This directory can be ignored.)
public: Contains band member sound files in the stage_sounds directory
src: In the app/routes subdirectory, this is where all the React files for every page can be found.
